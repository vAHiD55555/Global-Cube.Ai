خلاصه در یک جمله

تو یک روم Matrix (Element) می‌سازی، دو حساب بات جدا می‌سازی. هر بات یک سرویس (Replit یا Termux) دارد که از Hugging Face Inference API برای تولید پاسخ استفاده می‌کند. من همهٔ مراحل، کدها و نکات ADHD‑friendly را در این فایل گذاشته‌ام.

فوری: اگر می‌خواهی من این فایل را به یک مخزن GitHub اضافه کنم و GitHub Pages بسازم، نام کاربری و اسم ریپو را همین‌جا بفرست.

  • چک‌لیست قدم‌به‌قدم برای اجرای سریع (Replit پیشنهاد شده برای موبایل)
  • دستورالعمل ساخت حساب Hugging Face و دریافت توکن
  • دستورالعمل ساخت حساب‌های Matrix و دعوت بات‌ها

  • نکات طراحی UX برای محیط «مینیمال و خلاقیتی» و تنظیمات برای جلوگیری از حواس‌پرتی
  • گزینهٔ آفلاین (اطلاعات دربارهٔ gpt4all / llama.cpp) و محدودیت‌ها

چک‌لیست سریع (شکسته به گام‌های کوچک)

هر آیتم را به بخش مربوط در پایین برو و مراحل دقیق را دنبال کن. برای هر مرحله فقط 5–15 دقیقه وقت بگذار، بعد استراحت کن.

قدم‌های مفصل — بخش ۱: Hugging Face (۵–۱۰ دقیقه)

  1. باز کن: https://huggingface.co
  2. ثبت‌نام کن (اگر نداری). بعد از ورود: Settings → Access Tokens → New token.
  3. نام توکن بزن: matrix-bot-token. Scope: inference or read. ساخته و کپی کن.
  4. یادداشت کن: API key را در جایی امن نگهدار (در Replit از بخش Secrets استفاده می‌شود).
نکته: لایهٔ رایگان HF محدودیت دارد؛ برای تست خوب است. اگر پس از مدتی به مشکل برخوردی، به من بگو تا گزینهٔ جایگزین پیشنهاد دهم.

قدم‌های مفصل — بخش ۲: Matrix و Element (۵–۱۵ دقیقه)

  1. نصب Element: از Play Store یا وب‌سایت رسمی Element نصب کن.
  2. یک حساب بساز (مثلاً روی matrix.org) — این حساب برای توست.
  3. دو حساب بات جدا بساز: هر کدام یک ایمیل/نام کاربری مجزا نیاز دارد. نام پیشنهادی: @aurora:matrix.org و @atlas:matrix.org.
  4. در Element یک روم خصوصی بساز و خودت + دو بات را دعوت کن.
  5. در تنظیمات روم: اگر می‌خواهی خطاهای کم‌تر و آرامش بیشتر،‌ notifications برای ربات‌ها را خاموش کن یا از قاعده mention-only استفاده کن.
اگر نخواستی خودت دو حساب بسازی، من می‌توانم راهنمایی کنم یا قدم‌های دقیق ساخت را برای موبایل مرحله‌به‌مرحله بنویسم.

قدم‌های مفصل — بخش ۳: استقرار بات‌ها (Replit — پیشنهادی برای موبایل)

چرا Replit؟ چون از مرورگر موبایل قابل استفاده است، نیازی به دانلود مدل روی گوشی نداری و سریع است.

الف) آماده‌سازی در Replit

  1. باز کن: https://replit.com و ثبت‌نام کن.
  2. New Repl → Python → اسم بگذار.
  3. در بخش Files، فایلی با نام matrix_hf_bot.py بساز و کد را پیست کن (کد کامل در پایین است).
  4. در بخش Secrets (Environment → Secrets) متغیرهای زیر را قرار بده:
    • MATRIX_USER = نام کاربری بات (مثلاً @aurora:matrix.org)
    • MATRIX_PASS = پسورد بات
    • HUGGINGFACE_API_TOKEN = مقدار token از HF
    • HF_MODEL = نام مدل در HF (پیش‌فرض: bigscience/bloomz-1b1)
    • SYSTEM_PROMPT = متن شخصیت بات (فارسی یا انگلیسی)
  5. Run را بزن. در کنسول پیام‌های لاگ را می‌بینی و بات شروع به sync می‌کند.
  6. برای بات دوم: یک Repl جدا بساز و مقادیر MATRIX_USER/MATRIX_PASS و SYSTEM_PROMPT را تغییر بده (مثلاً شخصیت متفاوت).
اگر Replit محدود یا خاموش شد، می‌توانیم از یک Repl کوچک استفاده کنیم یا روش Termux را امتحان کنیم.

کد کامل: matrix_hf_bot.py

این فایل را دقیقاً در Replit یا Termux بساز و اجرا کن
# matrix_hf_bot.py
# بات ساده Matrix که از Hugging Face Inference API استفاده می‌کند.
# نیازها: python, matrix-nio, aiohttp
# متغیرهای محیطی مورد نیاز:
# MATRIX_USER, MATRIX_PASS, HUGGINGFACE_API_TOKEN, HF_MODEL (اختیاری), SYSTEM_PROMPT (اختیاری)

import os
import asyncio
import aiohttp
from nio import AsyncClient, MatrixRoom, RoomMessageText

HOMESERVER = os.environ.get("MATRIX_HOMESERVER", "https://matrix.org")
MATRIX_USER = os.environ["MATRIX_USER"]
MATRIX_PASS = os.environ["MATRIX_PASS"]
HUGGINGFACE_TOKEN = os.environ["HUGGINGFACE_API_TOKEN"]
HF_MODEL = os.environ.get("HF_MODEL", "bigscience/bloomz-1b1")
MAX_NEW_TOKENS = int(os.environ.get("MAX_NEW_TOKENS", "200"))

async def query_hf(prompt: str) -> str:
    url = f"https://api-inference.huggingface.co/models/{HF_MODEL}"
    headers = {"Authorization": f"Bearer {HUGGINGFACE_TOKEN}", "Accept": "application/json"}
    payload = {"inputs": prompt, "parameters": {"max_new_tokens": MAX_NEW_TOKENS, "do_sample": False}}
    async with aiohttp.ClientSession() as session:
        async with session.post(url, headers=headers, json=payload, timeout=120) as resp:
            if resp.status == 200:
                data = await resp.json()
                if isinstance(data, dict) and "error" in data:
                    return "خطا در مدل: " + data["error"]
                if isinstance(data, list):
                    text = data[0].get("generated_text") or data[0].get("summary_text") or str(data[0])
                    return text
                return str(data)
            else:
                text = await resp.text()
                return f"HTTP {resp.status}: {text}"

async def main():
    client = AsyncClient(HOMESERVER, MATRIX_USER)
    await client.login(MATRIX_PASS)

    async def message_callback(room: MatrixRoom, event: RoomMessageText):
        if event.sender == MATRIX_USER:
            return
        body = event.body.strip()
        # قاعده: فقط در DM یا وقتی mention شده پاسخ بده
        is_dm = room.is_direct if hasattr(room, 'is_direct') else (len(room.users) <= 2)
        username = MATRIX_USER.split(":")[0].lstrip("@").lower()
        mentioned = username in body.lower() or ("@" in body and username in body.lower())
        if is_dm or mentioned:
            system_prompt = os.environ.get("SYSTEM_PROMPT", "تو یک دستیار مختصر و خلاق هستی. پاسخ‌ها کوتاه و عملی باشند.")
            prompt = f"{system_prompt}\n\nUser: {body}\nAssistant:"
            await client.room_typing(room.room_id, timeout=1000)
            resp_text = await query_hf(prompt)
            await client.room_send(
                room.room_id,
                message_type="m.room.message",
                content={"msgtype": "m.text", "body": resp_text}
            )

    client.add_event_callback(message_callback, RoomMessageText)
    print("Bot started. Syncing...")
    await client.sync_forever(timeout=30000)

if __name__ == "__main__":
    asyncio.get_event_loop().run_until_complete(main())

نکات طراحی UX برای فضای «مینیمال و خلاقیت‌محور» (ADHD‑friendly)

  • هر وظیفه را به قطعات 5–15 دقیقه‌ای تقسیم کن — بعد از هر بخش یک استراحت کوتاه 2–3 دقیقه‌ای بگیر.
  • از قواعد پاسخ‌دهی بات استفاده کن: mention-only یا از ری‌اکشن/دکمه برای فراخواندن بات استفاده کن.
  • حداکثر طول پاسخ: MAX_NEW_TOKENS=150 — این کمک می‌کند پاسخ‌ها کوتاه و هدف‌گرا بمانند.
  • برای هر بات یک system prompt کوتاه و روشن بنویس (۳–۴ جمله).
  • برای جلوگیری از شلوغی، هر موضوع مهم را در یک topic یا روم جدا نگه دار.

گزینهٔ آفلاین (اطلاعات مروری)

  • دانلود وزن‌ها چند گیگابایت است.
  • معمولاً سرعت روی گوشی کند است مگر گوشی خیلی قوی داشته باشی.
  • نصب و پیکربندی پیچیده‌تر است، اما حریم خصوصی کامل دارد.
